# route-planner：路径规划

> 工具映射：地名消歧=`search_place`（+`route_query` 内置确认流程）；路线查询=`route_query`；周边设施=`search_nearby`；景区开放/天气/路况/末班车等现实约束=`web_search`/`web_fetch`。
> 核心原则：**硬约束 > 用户偏好**；先消歧再查线，首尾衔接闭环。

## 1. 需求定义

规划前先把行程要素定义清楚，缺失时向用户发起询问：

```json
{
  "trip": { "start": "2026-09-08 08:00", "end": "2026-09-12 20:00", "precision": "时" },
  "origin": "成都市",
  "destinations": ["四姑娘山", "新都桥", "稻城亚丁"],
  "transport_mode": "驾车",
  "vehicle": { "type": "租车", "rental": { "pickup": "神州租车双流机场店", "dropoff": "神州租车双流机场店" } },
  "preference": {
    "route_criteria": "balanced",
    "daily_driving_limit": 4,
    "must_visit": ["四姑娘山", "稻城亚丁"],
    "accommodation_budget": "中档",
    "reserve_ratio": 0.2
  }
}
```

字段含义：

- `trip`：整体时间范围与精度（日/时）；`origin` 出发地；`destinations` 计划依次前往的核心地点；
- `transport_mode`：驾车|公交|步行|骑行|打车|混合（对应 `route_query` 的 `mode`）；
- `vehicle`：工具归属（租车/私家车/公共交通）与租车取还点；
- `preference.route_criteria`：选路标准（fastest/shortest/cheapest/balanced，对应 `route_query` 的 `prefer`）；
- `preference.daily_driving_limit`：每日驾驶小时上限（硬约束）；
- `preference.must_visit`：不可舍弃的必去景点；`reserve_ratio`：全程预留时间缓冲比例。

## 2. 工具调用

### 2.1 地名消歧（search_place + route_query 内置确认）

地名不是唯一的，用户输入常含简称/错别字（"四姑娘山"可能指双桥沟/长坪沟/山镇；"新都桥"可能被误写为"新都乔"）。先用 `search_place(name=..., city=..., limit=5)` 把每个目的地解析为候选列表（名称/地址/坐标/置信度）：

```text
search_place(name="四姑娘山", city="阿坝", limit=5)
→ 四姑娘山风景区（双桥沟）0.95 / 四姑娘山风景区（长坪沟）0.90 / 四姑娘山镇 0.85 / …
```

选定规则：

- 默认取置信度第一的候选；
- 上下文明显指向其它类型时（"住在四姑娘山"→ 选镇），选对应类型中置信度最高者；
- 无 AMAP_KEY 时 `search_place` 走 LLM 兜底（不产坐标），坐标可在 `route_query` 确认流程中补足。

`route_query` 在起点/终点歧义时也会返回 `need_confirmation` + 候选列表：此时按对话上下文选定，把 `origin_confirmed` / `destination_confirmed` 设为候选完整名称后重调，其余参数不变。

### 2.2 路线查询（route_query）

```text
route_query(origin="神州租车双流机场店", destination="四姑娘山风景区（双桥沟）",
            mode="car", prefer="balanced", city="成都")
```

返回多方案 + 推荐（⭐），每方案含：距离、耗时、过路费(驾车)/票价(公交)/换乘(公交)/路线概要；`mode=taxi` 末尾追加打车估价；`prefer` 控制推荐排序。

选定规则：

- 按 `route_criteria` 排序：fastest 选耗时最短、cheapest 选费用最低、balanced 综合；
- 当日剩余时间紧张 → 优先 fastest；跨城长途预算有限 → 优先 cheapest；
- 返回路线含交通管制/严重拥堵标注 → 降权或剔除；
- 选中路线继续参与"首尾衔接"校验（终点是否靠近当日住宿地）。

### 2.3 周边设施（search_nearby）

餐饮、加油/充电、地铁站等用 `search_nearby(name=..., location="经度,纬度", keyword=?, radius=?)`。注意：

- 需 AMAP_KEY（未配置时不要调用）；
- `location` 中心点坐标先用 `search_place` 获取。

### 2.4 现实约束（web_search / web_fetch）

景区开放时间与闭园公告、极端天气预警、路段交通管制、公交末班车、门票预约等，用 `web_search` 检索、`web_fetch` 抓取景区官网/官方公告核实。时效要求：只取近几个月的公告，不取过往公告。

## 3. 路径规划规则

### 3.1 地名消歧与线路选优联动

1. 先消歧（`search_place`），把每个目的地解析为结构化 POI；
2. 再查线（`route_query`），依次查询相邻 POI 之间的多条候选路线；
3. 某段 top1 路线预估时长超过当日剩余可用时间 → 降级选更短路线（高速换国道），或拆分目的地；
4. 多段路径存在"折返跑"（A→B→A→C）→ 触发空间顺序重排，确认邻近 POI 后重组行程。

### 3.2 首尾衔接闭环

核心原则：上一条线路的终点必须在下一条线路起点的合理范围内。

1. 当日最后一个活动地点（通常是住宿地）必须是次日首个活动地点的起点；
2. 租车：取车点为第一段起点、还车点为最后一段终点，两者须一致或预留接驳时间；
3. 终点与下一段起点坐标距离 >500m（约 5 分钟步程）→ 告警并强制插入短途步行/打车接驳段（可用 `route_query` 的 `mode=walk` 校验短途步程）。

跨天状态传递：今晚住哪里决定明天从哪出发；今日剩余油量/电量决定明天是否先加油/充电。混合交通需无缝衔接（"驾车+步行"校验停车场到景区步程；"公交+打车"校验换乘接驳时间）。

### 3.3 餐饮与补给嵌入

1. 单段路径 >2 小时 → 在途经服务区/城镇插入 15–20 分钟休息节点；
2. 路径途经城镇 → `search_nearby` 获取周边餐饮，嵌入午/晚餐时间窗；
3. 自驾 → 把 `route_query` 路线概要中的途经点拆为子段，插入加油/充电节点。

时间不是简单加减：地图"驾驶时长"是纯行驶时间，实际还要加加油/充电、堵车、休息、用餐（用 `reserve_ratio` 预留缓冲）。

## 4. 风险规避（硬约束 > 用户偏好）

硬约束（不可妥协）：

- 途经区域极端天气预警（台风/暴雨/暴雪）→ 强制绕行或取消该段（`web_search` 核实）；
- 目的地景区当日闭园（`web_search`/`web_fetch` 核实开放公告）→ 替换周边可替代景点；
- 累计驾驶时长超过 `daily_driving_limit` → 重新规划（拆分目的地或调整住宿点）；
- 最后一段到达时间晚于当日可入住/天黑时间 → 提前出发或调整住宿点；
- 公交/地铁末班车早于预估到达时间 → 切换打车/自驾方案。

软约束（可优化）：

- 费用超预算 → 从 `route_query` 返回中选 cheaper 替代路线；
- 用户偏好"不走高速"但 fastest 含高速 → 选 balanced/shortest 国道方案；
- 路径涉及高海拔（>3500m）→ `web_search` 检索海拔数据并标注适应建议。

## 5. 输出规范

输出结构化日程，并显式附上地名消歧与路径选优的决策依据：

```text
## 行程概览
- 总天数：5 天 | 总里程：约 1100 km | 总驾驶时长：约 18 小时
- 交通方式：租车自驾（取还车：成都双流机场）

## Day 1（2026-09-08）
- 08:00-08:30 取车（成都双流机场）
- 08:30-12:10 驾车：成都 → 四姑娘山（route_query 选 fastest：高速，3h40min，过路费 95 元）
- 12:10-13:00 午餐（四姑娘山镇）
- 13:00-17:00 游览：四姑娘山·双桥沟（开放至 17:30，建议 4h）
- 17:00-17:30 驾车：四姑娘山 → 小金县（约 30km，0.5h）
- 18:00 入住酒店（小金县，海拔 2367m）
- 当日驾驶总时长：4h10min（含缓冲），符合安全阈值

## 地名消歧说明
- "四姑娘山"消歧出 5 个候选，取置信度第一"四姑娘山风景区（双桥沟）"（上下文为自驾游览）；住宿选"四姑娘山镇"转"小金县"（更匹配住宿需求）。

## 路径选优说明
- 成都 → 四姑娘山：route_query 返回多条路线，fastest（高速）3h40min、cheapest（全程国道）4h20min 省 95 元过路费；因首日需 17:30 前入园，选 fastest。

## 风险与备选
- ⚠️ 双桥沟需提前 1 天预约门票
- ⚠️ G350 路段可能有交通管制，出发前查路况
- 🔋 电车：四姑娘山镇有充电桩，小金县较少，建议提前补电
```

未核实的信息（开放时间/天气/预约等）须标注"待核实"或"基于现有证据的推断"，并附来源 URL。
